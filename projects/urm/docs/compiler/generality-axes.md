This is a **typed semantic backlog**, not a list of implemented kernels. A descriptor and independent references may be added before a native path. A new physical backend branch must pass the [charter's admission rule](compiler-charter.md#backend-branch-admission). The [architecture ledger](../planning/architecture-composition.md) maps all 76 mixer-relevant source rows to external calls and unresolved axes.

## Current execution boundary

At HEAD after the corrective integration (PAttention / HLA / Mamba-2 landed): 14 K1 dense-softmax fragments, one K3 route-to-state fragment and the K2 `linear_delta_state` fragments execute through the public graph path on the reference tier, **plus** PAttention (K1 `map_normalize` reducer, reference-tier), HLA (a two-node public K2 Nest graph) and Mamba-2's recurrent core (public head-gated matrix K2). The provider-decline contract is enforced: the native Triton, SDPA and NumPy-oracle K1 providers decline the score/reducer laws and the indexed path they do not execute (previously they accepted and silently ran softmax). The external Mamba-1 diagonal scan, the A4 hierarchical (log-linear) law, the UT triangular transforms (DeltaFormer/PaTH) and H3/Hyena remain external references without a public descriptor or native schedule. See the [integration review](../planning/architecture-urm-integration.md) and [evidence rules](../validation/evidence.md).

For every axis, record: descriptor and serialization; rejected combinations; NumPy/Torch references; two independent client graphs; source equations and proof obligations; provider capability; native forward/backward/decode envelope; end-to-end cost. A family label or axis label alone grants none of those stages.
